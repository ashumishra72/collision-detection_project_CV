# Collision Project

Detects instrument-tip collisions in a pattern-cutting simulation video using
a YOLO11n-seg tip tracker + an XGBoost classifier trained on human-annotated
ground truth.

## Structure

```
collision_project/
├── models/
│   ├── video_tip_circle_yolo11n_seg_best.pt   # tip/marker detector (TIPL, TIPR, TIPandCircle)
│   └── xgb_collision_classifier.json          # trained by 03_train_classifier.py
├── data/
│   ├── video.mp4                              # source video
│   ├── ground_truth.csv                       # generated by 01_convert_annotations.py
│   └── features_and_labels.csv                # generated by 02_extract_features.py
├── docs/
│   └── Pattern_Cutting_Annotation_1.docx      # source annotation table
├── scripts/
│   ├── 01_convert_annotations.py              # Word doc -> ground_truth.csv
│   ├── 02_extract_features.py                 # YOLO detections -> features_and_labels.csv
│   ├── 03_train_classifier.py                 # trains XGBoost, writes predictions.csv
│   └── 04_evaluate.py                         # metrics.json + charts
└── results/
    ├── predictions.csv
    ├── feature_importance.csv
    ├── metrics.json
    └── charts/
```

## Pipeline

```bash
pip install -r requirements.txt

python scripts/01_convert_annotations.py
python scripts/02_extract_features.py --sample-fps 5
python scripts/03_train_classifier.py
python scripts/04_evaluate.py
```

## Notes

- **Ground truth**: `docs/Pattern_Cutting_Annotation_1.docx` timestamps use an
  "M.SS" format (Word turned "mm:ss" into a number, e.g. `3.09` = 3:09). The
  conversion script parses this directly from the docx XML.
- **Features**: for each sampled frame, the YOLO model's TIPL/TIPR/TIPandCircle
  detections are turned into centroid positions, pairwise distances, bbox IoU,
  frame-to-frame speed, and segmentation-mask area (used as a monocular
  pseudo-depth cue — objects appear larger as they near the camera).
- **Labels**: a frame is labeled `label_collision=1` if its timestamp falls
  inside (±0.5s) any ground-truth event with a collision severity, and
  `label_near_miss=1` for near-miss events.
- **Train/test split** is chronological (first 80% of the timeline), not
  random, since randomly shuffling frames would leak adjacent-frame
  information between splits and inflate reported accuracy.
